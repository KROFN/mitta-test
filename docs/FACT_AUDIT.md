В каталоге **15** подтверждённых именованных/групповых позиций. Источник каждой позиции хранится внутри data model (`sourceLabel`, `sourceRefs`, `updated`).

- **«Глория»** — неоднозначное `90 × 200` для верхнего места сохранено с `*` и явной просьбой уточнить единицы/размер.
- **«Лагуна»** — multi-image set и характеристики происходят из публикации 30.04.2025; цена датирована.
- **«Вендетта»** — подтверждённого фото именно модели нет; интерфейс не подменяет его похожей фотографией и использует компактный no-photo state.
- **No-photo позиции** — «Соло», «Гамма 15», «Мори» и другие не получают декоративных fake placeholders или случайных кадров.

## Demo safety

Финальный release pass добавил во все 20 HTML shell:

```html
<meta name="robots" content="noindex,nofollow,noarchive">
```

Shell title/description и runtime metadata прямо называют сайт **неофициальным демонстрационным концептом**. В проекте нет Organization/Product JSON-LD, analytics/pixels и client-owned credentials. В footer есть ненавязчивая маркировка `Неофициальный демонстрационный концепт, 2026`.

## Итог

На дату release QA **известных выдуманных business/product claims в публичном интерфейсе не осталось**. Всё, что требует production-подтверждения, перечислено отдельно в `UNRESOLVED_FACTS.md`.
